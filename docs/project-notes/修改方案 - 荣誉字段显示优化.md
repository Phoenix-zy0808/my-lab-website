# 荣誉字段显示优化修改方案

## 修改目标
在荣誉列表前添加小圆点索引，调整字体大小和样式，使其与 bio 字段有明显区分。

---

## 具体修改方案

### 1. **添加小圆点索引**
- 使用无序列表 `<ul>` 和 `<li>` 标签替代当前的 `<p>` 标签
- 利用 CSS 的 `list-style-type: disc` 实现小圆点效果
- 或者使用 `::before` 伪元素自定义小圆点样式

### 2. **字体大小调整**
- 当前 bio 字体大小：`text-base`（约 16px）或 `text-gray-700`（默认大小）
- 荣誉字体大小调整为：`text-sm`（约 14px）
- 比 bio 小一个层级，但保持可读性

### 3. **字体样式区分**
- **颜色区分**：将荣誉文字颜色从 `text-gray-700` 改为 `text-gray-600` 或 `text-gray-500`，使其比 bio 稍浅
- **行高调整**：将 `leading-relaxed`（1.625）改为 `leading-normal`（1.5）或 `leading-snug`（1.375），使荣誉列表更紧凑
- **字重保持正常**：不使用加粗，保持常规字重 `font-normal`

### 4. **间距调整**
- 荣誉列表整体与 bio 之间增加上边距：`mt-4`（16px）
- 荣誉条目之间的间距：使用 `space-y-1`（4px）或 `space-y-1.5`（6px）
- 小圆点与文字之间的间距：通过 `list-inside` 或自定义 `padding-left` 控制

### 5. **具体修改位置**

#### 文件 1：`src/pages/team.vue`
需要修改 **3 个位置**：

当前代码：

## 技术说明

### Tailwind CSS 类说明
- `list-disc`: 使用实心圆点作为列表标记
- `list-inside`: 列表标记在内容区域内，与文字保持适当间距
- `text-sm`: 小字体（14px）
- `text-gray-600`: 中灰色文字
- `leading-normal`: 标准行高（1.5）
- `space-y-1.5`: 垂直间距 6px
- `mt-4`: 上边距 16px

### 兼容性
- 所有修改均基于现有 Tailwind CSS 框架
- 无需额外添加自定义 CSS
- 保持响应式设计兼容性
