## 二、详细修改说明

### 【P0】修改 1：PDF 查看器路径编码修复

**文件：** `src/components/PdfModal.vue`

**问题诊断：**
- PDF 路径包含中文字符
- iframe 的 src 属性直接使用编码后的路径会导致浏览器无法正确解析
- 需要使用 `encodeURI` 对完整 URL 进行编码，而不是路径本身

**修改内容：**

1. **添加 `getPdfSrc` 函数**（关键修复）

```javascript
// 获取正确的 PDF URL - 关键修复
function getPdfSrc(url: string | undefined) {
  if (!url) return ''
  // 确保路径以/开头
  const normalizedUrl = url.startsWith('/') ? url : `/${url}`
  // 使用 encodeURI 编码整个路径，但保留#toolbar=0
  const encodedUrl = encodeURI(normalizedUrl)
  return encodedUrl + '#toolbar=0'
}
```

2. **修改 iframe 的 src 属性**

```html
<!-- PDF iframe - 使用 getPdfSrc 函数 -->
<iframe
  v-if="!pdfLoading && !pdfError && pdfUrl"
  :src="getPdfSrc(pdfUrl)"
  w-full
  h-full
  border-0
  title="PDF Preview"
  @load="onPdfLoad"
  @error="onPdfError"
/>
```

3. **优化加载和错误状态**

```html
<!-- 加载状态 -->
<div v-if="pdfLoading" flex items-center justify-center h-full>
  <div text-center text-gray-500>
    <div i-carbon-circle-dash animate-spin text-4xl mb-4 />
    <p>PDF 加载中...</p>
  </div>
</div>

<!-- 错误状态 -->
<div v-else-if="pdfError" flex items-center justify-center h-full>
  <div text-center text-gray-500>
    <div i-carbon-document text-4xl mb-4 op="50" />
    <p>PDF 加载失败</p>
    <p text-sm mt-2>请尝试在新窗口打开</p>
  </div>
</div>
```

4. **添加错误日志**

```javascript
function onPdfError() {
  pdfLoading.value = false
  pdfError.value = true
  console.error('PDF 加载失败:', props.pdfUrl)
}
```

## 六、PDF 问题排查指南

如果 PDF 仍然无法显示，请按以下步骤排查：

### 1. 检查浏览器控制台

打开浏览器控制台（F12），查看是否有错误信息：
- CORS 错误
- 404 错误
- MIME type 错误

### 2. 检查 PDF 路径

在 `achievements.vue` 中添加调试代码：

```javascript
function openPdf(pdfUrl: string, title: string) {
  console.log('PDF 原始路径:', pdfUrl)
  const normalizedUrl = pdfUrl.startsWith('/') ? pdfUrl : `/${pdfUrl}`
  console.log('PDF 规范化路径:', normalizedUrl)
  console.log('PDF 完整 URL:', window.location.origin + normalizedUrl)
  currentPdfUrl.value = normalizedUrl
  currentPdfTitle.value = title
  showPdfModal.value = true
}
```

### 3. 直接访问 PDF

在浏览器地址栏直接输入 PDF 路径测试：
```
http://localhost:3333/pdfs/paper/翁丹妮论文录用.pdf
```

如果直接访问也打不开，说明是 Vite 静态资源配置问题。

### 4. 检查 Vite 配置

确保 `vite.config.ts` 包含：

```typescript
export default defineConfig({
  // ... 其他配置
  build: {
    assetsInclude: ['**/*.pdf'],
  },
})
```

### 5. 检查 public 目录

确保 PDF 文件位于 `public/pdfs/` 目录下：
```
public/
└── pdfs/
    └── paper/
        └── 翁丹妮论文录用.pdf
```
