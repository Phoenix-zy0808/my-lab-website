## 三、详细修改说明

### 【P0】修改 1：移除 DM Sans 字体

**文件：** `uno.config.ts`

**问题根源：**
DM Sans 字体的数字使用 Oldstyle Figures（旧式数字），如：
- 数字 `0, 1, 2` 高低错落，不符合常规阅读习惯
- 在中文环境下显示不协调

**修改内容：**

```typescript
// 修改前
import {
  defineConfig,
  presetAttributify,
  presetIcons,
  presetWebFonts,
  presetWind4,
} from 'unocss'

presets: [
  presetWind4(),
  presetAttributify(),
  presetIcons({...}),
  presetWebFonts({
    fonts: {
      sans: 'DM Sans',
      serif: 'DM Serif Display',
      mono: 'DM Mono',
    },
  }),
]

// 修改后
import {
  defineConfig,
  presetAttributify,
  presetIcons,
  presetWind4,
} from 'unocss'

presets: [
  presetWind4(),
  presetAttributify(),
  presetIcons({...}),
  // 移除 presetWebFonts，使用系统默认字体
]
```

**效果：**
- ✅ 数字显示为正常的等宽数字 (Tabular Figures)
- ✅ 字体渲染速度更快（无需加载 WebFont）
- ✅ 各平台使用最优系统字体

### 【P0】修改 4：Header 移动端菜单修复

**文件：** `src/components/Header.vue`

**核心代码：**

```javascript
// 监听菜单开关，控制 body 滚动
watch(isMobileMenuOpen, (val) => {
  if (val) {
    const scrollY = window.scrollY
    document.body.style.position = 'fixed'
    document.body.style.top = `-${scrollY}px`
    document.body.style.width = '100%'
    document.body.style.overflow = 'hidden'
    document.body.classList.add('menu-open')
  } else {
    document.body.style.position = ''
    document.body.style.top = ''
    document.body.style.width = ''
    document.body.style.overflow = ''
    document.body.classList.remove('menu-open')
    const scrollY = parseInt(document.body.style.top || '0')
    if (scrollY) {
      window.scrollTo(0, Math.abs(scrollY))
    }
  }
}, { immediate: true })
```

**模板部分：**

```html
<!-- 移动端菜单 - z-60 确保最高层级 -->
<div
  v-if="isMobileMenuOpen"
  class="fixed inset-0 z-60 lg:hidden"
>
  <!-- 菜单面板 -->
  <div
    class="absolute top-0 right-0 bottom-0 w-full max-w-[85vw] sm:max-w-sm bg-primary"
    @click.stop
    @touchmove.prevent
  >
    <!-- 菜单内容 -->
  </div>
</div>
```

**修复内容：**
- ✅ 层级提升至 `z-60`
- ✅ 添加 `@touchmove.prevent` 禁止菜单滚动
- ✅ 使用 `position: fixed` + `top` 锁定背景滚动
- ✅ 关闭菜单后恢复滚动位置

## 八、常见问题解答

### Q1: 数字字体还是奇怪？

**A:** 清除浏览器缓存后刷新页面，确保新的 CSS 生效：
- Chrome: `Ctrl + Shift + Delete` → 清除缓存
- 或使用无痕模式打开

---

### Q2: Footer 描述文字换行了？

**A:** 检查描述内容是否过长。`max-w-3xl` 约 768px，如果描述超过这个宽度会自然换行。这是正常现象。

---

### Q3: 荣耀 500 Pro 上菜单打开后背景仍然可滚动？

**A:** 检查 `body.menu-open` 样式是否正确应用：
```css
body.menu-open {
  overflow: hidden;
}
```
