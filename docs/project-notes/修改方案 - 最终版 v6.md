### 【P1】修改 2：PDF 打开 Toast 提示

**文件：** `src/pages/achievements.vue`

**问题：** 点击 PDF 后用户不知道发生了什么

**修改内容：**

1. **添加 Toast 状态**
```typescript
// Toast 提示状态
const showToast = ref(false)
const toastMessage = ref('')

function showTemporaryMessage(msg: string) {
  toastMessage.value = msg
  showToast.value = true
  setTimeout(() => (showToast.value = false), 3000)
}
```

2. **修改 openPdf 函数**
```typescript
function openPdf(pdfUrl: string, title: string) {
  showTemporaryMessage('正在打开 PDF...')
  const normalizedUrl = pdfUrl.startsWith('/') ? pdfUrl : `/${pdfUrl}`
  const encodedUrl = encodeURI(normalizedUrl)
  window.open(encodedUrl, '_blank', 'noopener,noreferrer')
}
```

3. **添加 Toast 组件到模板**
```vue
<!-- Toast 提示 -->
<transition
  enter-active-class="transition duration-300"
  enter-from-class="opacity-0 translate-y-4"
  enter-to-class="opacity-100 translate-y-0"
  leave-active-class="transition duration-200"
  leave-from-class="opacity-100"
  leave-to-class="opacity-0"
>
  <div
    v-if="showToast"
    class="fixed bottom-8 left-1/2 -translate-x-1/2 bg-black/80 text-white px-6 py-3 rounded-lg shadow-lg z-50 text-sm"
  >
    {{ toastMessage }}
  </div>
</transition>
```

**效果：**
- ✅ 点击 PDF 按钮后显示"正在打开 PDF..."提示
- ✅ 3 秒后自动消失
- ✅ 用户体验更友好

### 【P2】修改 3：回到顶部按钮

**文件：** 
- `src/components/BackToTop.vue` (新建)
- `src/App.vue` (引用)

**问题：** 长页面滚动后，用户需要手动滚回顶部

**新建 BackToTop.vue 组件：**

```vue
<script setup lang="ts">
import { useScroll } from '~/composables/useScroll'

const { isScrolled } = useScroll(300)

function scrollToTop() {
  window.scrollTo({ top: 0, behavior: 'smooth' })
}
</script>

<template>
  <transition ...>
    <button
      v-if="isScrolled"
      fixed
      bottom-8
      right-8
      w-12
      h-12
      rounded-full
      bg-primary
      text-white
      shadow-lg
      flex
      items-center
      justify-center
      hover:bg-primary-light
      transition
      duration-200
      z-40
      aria-label="回到顶部"
      @click="scrollToTop"
    >
      <div i-carbon-chevron-up text-xl />
    </button>
  </transition>
</template>
```

**修改 App.vue：**

```vue
<template>
  <div min-h-screen flex flex-col bg-white>
    <Header />
    <main flex-1>
      <RouterView />
    </main>
    <TheFooter />
    <BackToTop /> <!-- 添加这里 -->
  </div>
</template>
```

**效果：**
- ✅ 滚动超过 300px 后显示按钮
- ✅ 点击平滑滚动到顶部
- ✅ 带动画过渡效果

### 【P3】修改 8：生产环境 console 移除

**文件：** `vite.config.ts`

**问题：** 生产环境还保留 console.log/error

**修改内容：**

```typescript
// 修改前
build: {
  assetsInclude: ['**/*.pdf'],
}

// 修改后
build: {
  assetsInclude: ['**/*.pdf'],
  // 生产环境移除 console（使用 esbuild）
  minify: 'esbuild',
  esbuild: {
    drop: ['console', 'debugger'],
  },
}
```

**效果：**
- ✅ 生产环境自动移除 console.log/error/warn
- ✅ 移除 debugger 语句
- ✅ 减小包体积
