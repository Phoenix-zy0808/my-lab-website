## 二、详细修改说明

### 【P1】修改 1：useFetchData 添加缓存机制

**文件：** `src/composables/useFetchData.ts`

**问题：** 每次访问页面都重新请求数据，没有缓存

**修改内容：**

```typescript
// 添加缓存 Map
const cache = new Map<string, { data: any; timestamp: number }>()
const CACHE_DURATION = 5 * 60 * 1000 // 5 分钟

// 在 fetchData 函数中检查缓存
const fetchData = async () => {
  // 检查缓存
  const cached = cache.get(url)
  if (cached && Date.now() - cached.timestamp < CACHE_DURATION) {
    data.value = cached.data as T
    return
  }

  // ... 正常请求逻辑

  // 写入缓存
  cache.set(url, { data: result, timestamp: Date.now() })
}
```

**效果：**
- ✅ 5 分钟内相同 URL 使用缓存数据
- ✅ 减少重复请求
- ✅ 提升页面加载速度
- ✅ 内存自动管理（Map 自动清理）

### 【P2】修改 2：Hero 背景图添加占位

**文件：** `src/components/Hero.vue`

**问题：** Hero 背景图直接加载，没有占位图，加载慢时显示空白

**修改内容：**

1. **添加加载状态**
```typescript
const bgLoaded = ref(false)

function handleBgLoad() {
  bgLoaded.value = true
}

function handleBgError() {
  bgLoaded.value = true // 失败也标记为已加载
}
```

2. **添加渐变占位背景**
```vue
<section
  :style="{
    backgroundImage: background ? `url(${background})` : undefined,
    backgroundColor: bgLoaded ? 'transparent' : 'oklch(56% 0.062 207.6 / 0.2)',
  }"
>
  <!-- 渐变占位背景 -->
  <div
    v-if="!bgLoaded"
    class="absolute inset-0 bg-gradient-to-br from-primary/20 to-secondary/20"
    aria-hidden="true"
  />

  <!-- 隐藏图片用于监听加载 -->
  <img
    v-if="background"
    :src="background"
    class="hidden"
    @load="handleBgLoad"
    @error="handleBgError"
    alt=""
    aria-hidden="true"
  />
</section>
```

**效果：**
- ✅ 加载时显示渐变背景
- ✅ 加载完成后显示图片
- ✅ 加载失败也优雅降级
- ✅ 首屏体验更好

### 【P3】修改 5：性能监控

**文件：** 
- `src/composables/usePerformance.ts` (新建)
- `src/main.ts` (使用)

**新建 usePerformance.ts：**

```typescript
export function usePerformance() {
  const reportPerformance = () => {
    if (typeof window === 'undefined' || !window.performance) return

    const navigation = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming

    const metrics = {
      // 页面加载总时间
      loadTime: navigation.loadEventEnd - navigation.startTime,
      // DOM 就绪时间
      domReady: navigation.domInteractive - navigation.startTime,
      // 首次内容绘制
      fcp: performance.getEntriesByName('first-contentful-paint')[0]?.startTime || 0,
      // 首次有意义绘制
      fmp: performance.getEntriesByName('first-meaningful-paint')[0]?.startTime || 0,
    }

    // 开发环境输出
    if (import.meta.env.DEV) {
      console.log('📊 性能指标:', {
        '加载总时间': `${metrics.loadTime.toFixed(2)}ms`,
        'DOM 就绪时间': `${metrics.domReady.toFixed(2)}ms`,
        '首次内容绘制': `${metrics.fcp.toFixed(2)}ms`,
        '首次有意义绘制': `${metrics.fmp.toFixed(2)}ms`,
      })
    }

    // 生产环境可以发送到分析服务
    if (import.meta.env.PROD) {
      // TODO: 集成分析服务
    }
  }

  onMounted(reportPerformance)
  return { reportPerformance }
}
```

**在 main.ts 中使用：**

```typescript
import { usePerformance } from './composables/usePerformance'

// ...

const { reportPerformance } = usePerformance()
reportPerformance()
```

**效果：**
- ✅ 开发环境输出性能指标
- ✅ 监控页面加载速度
- ✅ 为性能优化提供数据支持
- ✅ 预留生产环境分析接口

## 八、后续建议

### 图片压缩（可选）

如果需要进一步优化图片加载，可以运行以下命令：

```bash
# 安装图片压缩工具
pnpm add -D imagemin imagemin-pngquant imagemin-mozjpeg

# 创建压缩脚本（scripts/compress-images.js）
# 运行压缩
node scripts/compress-images.js
```

### CDN 配置（可选）

如果需要 CDN 加速，可以：

1. 添加环境变量 `.env`
```
VITE_CDN_URL=https://cdn.example.com
```

2. 修改图片路径
```typescript
const CDN_BASE = import.meta.env.VITE_CDN_URL || ''
const getImageUrl = (path: string) => CDN_BASE + path
```
