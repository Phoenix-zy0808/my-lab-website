### 【P0】修改 2：Header 移动端菜单修复

**文件：** `src/components/Header.vue`

**核心代码：**

```javascript
// 监听菜单开关，控制 body 滚动
watch(isMobileMenuOpen, (val) => {
  if (val) {
    const scrollY = window.scrollY
    document.body.style.position = 'fixed'
    document.body.style.top = `-${scrollY}px`
    document.body.style.width = '100%'
    document.body.style.overflow = 'hidden'
    document.body.classList.add('menu-open')
  } else {
    document.body.style.position = ''
    document.body.style.top = ''
    document.body.style.width = ''
    document.body.style.overflow = ''
    document.body.classList.remove('menu-open')
    const scrollY = parseInt(document.body.style.top || '0')
    if (scrollY) {
      window.scrollTo(0, Math.abs(scrollY))
    }
  }
}, { immediate: true })
```

**模板部分：**

```html
<!-- 移动端菜单 - z-60 确保最高层级 -->
<div
  v-if="isMobileMenuOpen"
  class="fixed inset-0 z-60 lg:hidden"
  @touchmove.prevent
>
  <!-- 菜单面板 -->
  <div
    class="absolute top-0 right-0 bottom-0 w-full max-w-[85vw] sm:max-w-sm bg-primary"
    @click.stop
  >
    <!-- 菜单内容 -->
  </div>
</div>
```

**修复内容：**
- ✅ 层级提升至 `z-60`
- ✅ 添加 `@touchmove.prevent` 禁止菜单滚动
- ✅ 使用 `position: fixed` + `top` 锁定背景滚动
- ✅ 关闭菜单后恢复滚动位置

### 【P1】修改 4：全局移动端样式

**文件：** `src/styles/main.css`

**核心优化：**

```css
/* 禁止移动端双击缩放 */
* {
  touch-action: manipulation;
}

/* 禁止点击高亮 */
button, a {
  -webkit-tap-highlight-color: transparent;
  -webkit-touch-callout: none;
}

/* 菜单打开时禁止滚动 - 修复 Android 滚动穿透 */
body.menu-open {
  overflow: hidden;
  position: fixed;
  width: 100%;
}

/* 安全区域适配 - 刘海屏/曲面屏 */
.safe-top {
  padding-top: env(safe-area-inset-top);
}

/* Android 字体渲染优化 */
@media screen and (-webkit-min-device-pixel-ratio: 0) {
  body {
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
  }
}

/* 修复 Android Chrome 地址栏影响 100vh 问题 */
@supports (height: 100dvh) {
  html {
    height: 100dvh;
  }
}

/* 小屏设备优化 (< 375px) */
@media screen and (max-width: 374px) {
  .hero-title {
    font-size: 1.5rem !important;
  }
}

/* 确保按钮和链接有足够的点击区域 (至少 44x44px) */
@media screen and (max-width: 768px) {
  button, a {
    min-height: 44px;
    min-width: 44px;
  }
}
```
