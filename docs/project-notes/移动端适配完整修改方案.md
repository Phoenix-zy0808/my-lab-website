## 一、问题诊断总结

### 🔴 P0 级问题（严重影响用户体验）

1. **Header 移动端菜单打开后内容重复显示**
   - 两层标题区域同时出现
   - 菜单层级不足，无法完全覆盖底层内容

2. **Footer 布局在移动端完全崩坏**
   - 硬编码 `margin-left: 8rem` 导致内容错位
   - Grid 布局未正确降级为单列

3. **Android 滚动穿透问题**
   - 菜单打开时背景页面可滚动
   - 荣耀/华为设备尤为明显

### 🟠 P1 级问题（影响部分功能使用）

4. **Hero 区域在移动端过高** - 浪费屏幕空间
5. **首页悬浮卡片在移动端溢出** - 负 margin 未做响应式处理
6. **各页面筛选器/Tabs 横向溢出** - 无法完整显示所有选项
7. **缺少 viewport meta 标签优化** - 无法充分利用全面屏

### 🟡 P2 级问题（体验优化）

8. **缺少安全区域适配** - 刘海屏/曲面屏设备显示异常
9. **Android 特定兼容性问题** - 字体渲染、点击延迟、100vh 问题
10. **缺少设备检测能力** - 无法针对特殊设备优化

## 三、完整修改方案

### 【P0】修改 1：Header 移动端菜单彻底修复

**文件：** `src/components/Header.vue`

**问题分析：**
- 移动端菜单 `z-40` 低于 header 的 `z-50`
- 菜单打开时没有遮罩层
- **Android 滚动穿透问题**（荣耀/华为设备严重）
- 菜单内容没有做响应式限制

**已完成的修改：**

```javascript
// 新增：监听菜单开关，控制 body 滚动（修复 Android 滚动穿透）
watch(isMobileMenuOpen, (val) => {
  if (val) {
    // 保存当前滚动位置
    scrollPosition.value = window.scrollY
    // 使用 fixed + top 来锁定滚动位置
    document.body.style.position = 'fixed'
    document.body.style.top = `-${scrollPosition.value}px`
    document.body.style.width = '100%'
    document.body.style.overflow = 'hidden'
    document.body.classList.add('menu-open')
  } else {
    // 恢复滚动位置
    document.body.style.position = ''
    document.body.style.top = ''
    document.body.style.width = ''
    document.body.style.overflow = ''
    document.body.classList.remove('menu-open')
    // 恢复到之前的滚动位置
    window.scrollTo(0, scrollPosition.value)
  }
}, { immediate: true })
```

**层级提升：** `z-40` → `z-60`

**触摸优化：** 添加 `@touchmove.prevent` 禁止菜单滚动

### 【P2】修改 9：设备检测 Composable

**文件：** `src/composables/useDeviceDetect.ts` (新建)

**已创建：**

```typescript
import { useMediaQuery } from '@vueuse/core'
import { computed } from 'vue'

export function useDeviceDetect() {
  // 基础断点
  const isMobile = useMediaQuery('(max-width: 768px)')
  const isTablet = useMediaQuery('(min-width: 769px) and (max-width: 1024px)')
  const isDesktop = useMediaQuery('(min-width: 1025px)')

  // 精确设备检测
  const isSmallMobile = useMediaQuery('(max-width: 374px)')
  const isNormalMobile = useMediaQuery('(min-width: 375px) and (max-width: 429px)')
  const isLargeMobile = useMediaQuery('(min-width: 430px) and (max-width: 768px)')

  // 特殊屏幕检测
  const hasNotch = useMediaQuery('(min-width: 375px) and (min-height: 812px)')
  const isFoldable = useMediaQuery('(min-width: 600px) and (max-width: 800px) and (min-height: 1000px)')

  // 横屏检测
  const isLandscape = useMediaQuery('(orientation: landscape)')

  // 触摸设备检测
  const isTouch = useMediaQuery('(pointer: coarse)')

  // 设备类型
  const deviceType = computed(() => {
    if (isFoldable.value) return 'foldable'
    if (isTablet.value) return 'tablet'
    if (isDesktop.value) return 'desktop'
    if (isSmallMobile.value) return 'small-mobile'
    if (isLargeMobile.value) return 'large-mobile'
    if (isMobile.value) return 'mobile'
    return 'unknown'
  })

  return {
    isMobile, isTablet, isDesktop,
    isSmallMobile, isNormalMobile, isLargeMobile,
    hasNotch, isFoldable, isLandscape,
    isTouch, deviceType,
  }
}
```

**使用示例：**

```vue
<script setup>
import { useDeviceDetect } from '~/composables/useDeviceDetect'

const { isMobile, hasNotch, deviceType } = useDeviceDetect()
</script>

<template>
  <div :class="hasNotch ? 'safe-top' : ''">
    <span v-if="isMobile">移动端视图</span>
    <span v-else>桌面端视图</span>
  </div>
</template>
```

## 八、常见问题解答

### Q1: 荣耀 500 Pro 上菜单打开后背景仍然可滚动？

**A:** 检查 `body.menu-open` 样式是否正确应用，确保：
```css
body.menu-open {
  overflow: hidden;
  position: fixed;
  width: 100%;
}
```

### Q2: 华为 Mate 70 Pro 上字体显示过粗？

**A:** 鸿蒙系统字体渲染偏粗，已在 CSS 中添加优化：
```css
@media screen and (-webkit-min-device-pixel-ratio: 0) and (min-resolution: 3dppx) {
  .hero-title {
    font-weight: 500;
  }
}
```

### Q3: 小折叠屏外屏显示异常？

**A:** 针对 < 375px 宽度已添加特殊样式：
```css
@media screen and (max-width: 374px) {
  .hero-title {
    font-size: 1.5rem !important;
  }
}
```
